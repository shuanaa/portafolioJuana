## Verlo localmente

No necesita build. Levantalo con un servidor estático:

```bash
npx serve .
```

y abrí `http://localhost:3000`.

## Deploy

Se publica con **GitHub Pages** desde la rama `main`, carpeta `/ (root)`. Cada push a `main` actualiza el sitio en 1-2 minutos.

## Estructura

```
index.html        CV completo (HTML + estilos en el mismo archivo)
main.html         redirección a index.html para links viejos
public/images/    foto, capturas de proyectos y PDFs
```
